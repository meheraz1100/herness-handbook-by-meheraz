Testing and improving an agent harness

The harness is everything around the model: the loop, the tools, the sandbox, the checks and the context. This guide covers the methods frontier labs use to test a harness, improve it, and then fold the gains into smaller models. Each method has the procedure, a worked example, what it measures, what to watch out for, and where it comes from.

1 · Test

Measure reliability

Run the agent on fixed tasks and grade the outcome, the steps and the cost.

M1–M9, X1, H2–H3
2 · Diagnose

Read the failures

Pull failing transcripts. Treat each failure as a bug in the harness, not in the model.

R1–R2
3 · Improve

Change the harness

Fix tools, rules, context and runtime access. Rerun the held-out tests.

I1–I9, H1, H4–H8
4 · Fold in

Train smaller models

Use the improved harness to produce verified trajectories and train on them.

D1–D6, X2

Then the loop repeats: a smaller model that has absorbed the harness frees the harness to take on longer or harder tasks.
